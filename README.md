# TITUS-THE-FOX-SQZ-COMP-DECOMP
Decompressor and compressor for Titus the Fox (MSDOS). Probably works on Prehistorik and Prehistorik II.

Two python scripts created with claude:
- patch_palette: changes EGA palette to make EGA version look better.
- python_sqz_lzw: 16/156 color BMP to SQZ; SQZ to bmp 16 colors (title and menu images). BIN to SQZ; SQZ to BIN;
